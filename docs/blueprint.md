# **App Name**: QR Attendance

## Core Features:

- Admin Login: Secure login for the administrator (admin@admin.com / admin).
- User Registration: User registration with full name and Colombian ID (unique).
- QR Code Generation: Automatic QR code generation with user data.
- QR Code Display: Display QR codes for the administrator and users.
- Attendance Scanning: QR code scanning for attendance registration.
- Attendance Control Panel: Control panel displaying a list of registered attendances.
- Record attendance: Attendance is recorded with date and time.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to convey trust and reliability, reflecting the app's essential function in tracking attendance.
- Background color: Light blue (#E0F7FA) for a clean and professional look, creating a comfortable visual experience.
- Accent color: Soft orange (#FFB347) to highlight interactive elements and important actions.
- Body and headline font: 'PT Sans', a humanist sans-serif, for its modern yet approachable feel suitable for both headings and body text. Note: currently only Google Fonts are supported.
- Use simple, clear icons for navigation and key functions like scanning and user management.
- A clean and intuitive layout ensures easy navigation, especially for attendance records and QR code scanning.
