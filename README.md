# CheckIn

## Descripción

**CheckIn** es una aplicación de control de asistencia basada en códigos QR. Permite a los administradores gestionar usuarios, generar códigos QR únicos y registrar la entrada y salida del personal de manera eficiente. Los usuarios pueden ver su historial de asistencia y su código QR personal.

## Uso

La aplicación cuenta con las siguientes funcionalidades principales:

-   **Login de Administrador**: Inicio de sesión seguro para administradores (`admin` / `admin`).
-   **Registro de Usuarios**: Los usuarios pueden registrarse con su nombre completo y cédula colombiana.
-   **Generación de Códigos QR**: Se genera automáticamente un código QR con los datos del usuario tras el registro.
-   **Escaneo de Asistencia**: Los administradores pueden escanear los códigos QR para registrar la entrada y salida.
-   **Panel de Control**: Un panel para administradores que muestra la lista de asistencias registradas y permite la gestión de usuarios.
-   **Historial de Asistencia**: Los usuarios pueden consultar su propio historial de entradas y salidas y exportarlo.

## Tecnologías Utilizadas

-   **Framework**: Next.js (con App Router)
-   **Lenguaje**: TypeScript
-   **UI**: React, ShadCN UI
-   **Estilos**: Tailwind CSS
-   **Base de Datos**: Firebase (Firestore)
-   **Inteligencia Artificial**: Genkit
-   **Autenticación**: Gestión de sesión personalizada
